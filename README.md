#  Pequenos Momentos

## Sobre o projeto

**Pequenos Momentos** 
é uma página Web desenvolvida no âmbito
de um curso de HTML e CSS.

O projeto pretende mostrar a importância de valorizar as
pequenas coisas do dia a dia, como a natureza, os animais
e os momentos de tranquilidade.

##  Objetivos

- Criar uma página Web simples e responsiva.
- Utilizar HTML5 para estruturar os conteúdos.
- Aplicar CSS3 para personalizar o aspeto da página.
- Utilizar imagens e links internos e externos.
- Criar um formulário de contacto.
- Aplicar Flexbox e Media Queries.

## Tecnologias utilizadas

- **HTML5** - Estrutura da página.
- **CSS3** - Estilos e apresentação visual.
- **Flexbox** - Organização dos elementos.
- **Media Queries** - Adaptação a diferentes ecrãs.

##  Conteúdo da página

A página está organizada em várias secções:

1. **Início** - Apresentação do tema.
2. **Sobre mim** - Pequena apresentação pessoal.
3. **Inspirações** - Cartões sobre natureza, animais e vida simples.
4. **Galeria** - Conjunto de fotografias.
5. **Contacto** - Formulário para deixar uma mensagem.

##  Design responsivo

Foi utilizada uma Media Query com `max-width: 768px`
para adaptar a organização dos cartões a ecrãs mais pequenos.

Nos telemóveis, os cartões passam a aparecer
um por baixo do outro.

##  Como visualizar o projeto

1. Abrir a pasta do projeto.
2. Localizar o ficheiro `index.html`.
3. Abrir o ficheiro num navegador Web.

Não é necessária nenhuma instalação adicional.
